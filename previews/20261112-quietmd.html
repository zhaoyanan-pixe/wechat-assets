我的笔记现在散在四个地方：飞书云文档、桌面上几个 txt、G 盘一个 md 文件夹，还有微信收藏。

上个月想找一句三个月前记的话，四个地方翻了一遍，没找到。最后重新搜了一遍资料，等于白记。

这种事干过两次以后，我开始认真看「笔记到底存在哪」这个问题。然后就撞见一个只有 11 天大的项目。

它叫 Quiet.md，11 月 1 日建的仓库，到今天早上 1,600 多星。Rust 写的，MIT 协议，Mac、Windows、Linux 三个平台都有安装包。作者自己给它的定位是「一个又快又安静的本地笔记应用」。

整个笔记库，就是一个普通文件夹

它不搞账号，也不搞云同步。笔记库默认放在「文稿」里一个独立文件夹，每篇笔记对应一个 XML 文件，你粘进去的图和附件单独放一个 assets 文件夹。

笔记库的真实目录结构（照官方文档 docs/FORMAT.md 抄的，文件名已缩短）

这句话的分量在于：这份文件不认 Quiet.md。哪天这软件不更新了、你换电脑了，文件夹整个拷走，随便一个文本编辑器也能打开。

它用的不是私有二进制格式，是飞书文档那套 DocxXML。这一点下面单独说。

还有两个细节挺对胃口：Windows 上卸载软件不会删你的笔记；安装包 12.9MB，装完不塞后台服务、不开机自启。

它说的是飞书的方言

这是我完全没想到的设计。作者把笔记的存储格式，直接做成了飞书云文档的 DocxXML。

意思是：从飞书复制一段带表格、待办、分栏的内容粘进来，结构还在；反过来把本地写的贴回飞书，也不会散架。导入支持 Markdown 和飞书文档，导出支持 Markdown、PDF，还能直接打印。

我为什么在意这个：这几年我换过三次笔记工具，每次最痛的不是学新界面，是把旧文档搬出来。表格变图片、待办变项目符号、分栏直接消失。

它内置了四套配色：Craft、飞书、Notion、Obsidian。看得出来，作者盯的就是「不想搬，但想换」的那批人。

官方界面截图：左侧文档树，右侧所有笔记平铺（来源：仓库 docs/images/home.png）

首发体验也做了：第一次打开，它会往空库里放一份「开始指南」，十分钟带你过一遍主要功能，不会覆盖你已经有的笔记。界面中英双语，中文是原生的。

快，是那种不用等的快

这软件不是网页套壳（那种一个记事本能吃几百兆内存的做法）。界面由 Rust 和 GPUI 直接在显卡上画出来。

官方给了一组数：在一篇 100 万字、549 章的文档里连续操作 100 次，打字每帧的处理耗时 P95 是 5.78 毫秒，退格 5.55 毫秒，滚动 4.14 毫秒。

（P95 是什么：把 100 次操作按耗时排队，第 95 名那个的耗时。它比平均值诚实，因为把「偶尔卡一下」也算进去了。）

120Hz 屏幕给每一帧的预算是 8.3 毫秒。也就是说在百万字文档里，它还有余量。

这类数字我一向打折看，毕竟测试机是 M5 Pro。但只要它别在一篇长文里卡成幻灯片，对我这种天天写几千字的人就够用了。

再说清楚它现在的问题

它挂着一个 Beta 标签，11 天发了 11 个版本，平均一天一版。开发快是好事，反过来也说明现在还不是「闭眼存进去」的时候，仓库里 73 个 issue 还开着。

仓库发布页实拍：11 天 11 个版本，最新 v0.1.10（2026-11-12 08:02 本机实截）

Windows 第一次运行可能弹 SmartScreen 拦截，得点「更多信息 → 仍要运行」。这不是病毒提示，是没买微软签名证书的小团队常态。

重要笔记先备份。它卸载不删笔记，但回收站里的「一键清空」是真的删掉；Beta 阶段，别把唯一一份资料放进去当实验。

另外两个小地方值得知道：它自带的 67 个图标是 Nucleo 商业授权，不能单独抠出来再分发；「Quiet.md」这个名字和图标也不在 MIT 协议范围内。你拿它改个自己的版本可以，这两样得先换掉。

项目关键数字（GitHub API / Releases API，2026-11-12 08:05 采集）

谁适合，谁先别装

适合的人：笔记量大、在意文件归属、同时又在用飞书办公。

还有个隐藏用处：从 0.1.8 版起，它能原地编辑本机的 .md 文件，也能把整个文件夹导进来但不改后缀。我那个 G 盘的 md 知识库，理论上可以直接挂进去看。

先别装的：要多人协作、要手机端随时改、要把笔记发成链接给别人的。它没有账号体系，也没有手机版。

我的判断是拿一篇废稿试两天，别急着搬全部笔记。先让它证明不丢字、不卡顿，再谈换不换。
