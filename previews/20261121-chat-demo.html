我电脑里装过的 AI 客户端，两只手数不过来。

每换一台机器，就要重新登录一遍，聊天记录还各在各家。用久了会冒出一个念头：这入口要是归我自己就好了。

所以那天在 GitHub 上刷到 deepseek-ai/chat-demo，我停了一下。点进去确认了两遍：是 DeepSeek 官方账号，不是同名仿的。

9 天，5,167 星，1,189 次 fork。它开源的既不是模型，也不是接口，而是你每天盯着看的那个聊天界面。

先看清楚它是什么

官方给它的定位很老实：一个「聊天示例」，demo。

我更喜欢叫它样板间——装修好了，水电都通，拎包能住，也能砸墙重改。

它最特别的地方是没有后端。整个应用都是静态文件，浏览器拿着你的 key，直接去敲 DeepSeek 的接口。不用服务器，不用数据库，也不用运维。

官方给了两条用法：打开在线演示页，设置里填上 API Key，直接聊；或者去 Releases 下载压缩包，解压后打开 index.html，不用安装、不用构建。README 里也补了一句：直接打开文件，需要浏览器允许本地文件的存储和跨域请求。

官方在线演示页（截图：2026-11-21）：左边会话，中间一句「今天有什么可以帮到你？」，底下是深度思考、智能搜索两个开关

我把最新版 v0.1.3 的包下下来了：1.8MB，解压出 153 个文件，根目录一个 index.html、一个 static 文件夹、一张 MIT 许可证。整个仓库只有 7 次提交，代码不厚，想动手改的人翻得动。

仓库里还自带一条 GitHub Pages 的自动发布配置：推一次代码，它自己构建、自己上线。官方演示页就是这么挂上去的。

界面不是空壳

多会话、自动起标题、改名删除；一条提问改一版重答；回答可以分叉，像树一样往回切。同一个问题想比较两种问法，不用重开对话：分叉出来的回答各自留着，随时切回去。

官方 README 列出的功能（本号据 README 整理）

流式输出、深度思考开关、智能搜索，搜索到的结果和读过的网页会带来源链接。附件能传、能拖、能粘贴；语音能输入，回答也能念出来。

公式、代码高亮、流程图都认；中英文、明暗主题、手机布局；聊天记录能打包导出，换台电脑再导回去。

这些东西单拎出来都不新鲜。可它们凑在一个 1.8MB 的压缩包里，还是官方自己写的，就有点意思了。

真正值钱的，是那面「墙」

我们评价一个 AI 产品，习惯看模型跑分。可你每天真正摸到的，是会话列表，是输入框，是那条「正在思考」的动画。

模型是水电，界面是装修。DeepSeek 这次把装修图纸也给了：哪面墙能砸、插座在哪、灯怎么走线，全摊开。

没有后端这件事，对小团队尤其友好。丢到 GitHub Pages 或任意静态托管上就能跑；给团队、给家里人做一个专属入口，成本几乎为零。

以前做同样的事，要买服务器、配域名、写登录。现在一个文件夹，改个名字就能上线。

仓库首页（截图：2026-11-21）：5.2k 星、1.2k fork，README 第一句就写「无需应用后端」

再往深想一层：模型厂商卖的是调用量。把界面开源，等于把「怎么把模型用起来」这道题的标准答案发下去。用的人越多，API 调用越多。这笔账，DeepSeek 算得明白。

三盆冷水

第一盆：它不是 DeepSeek 的正式网页版。官方写的是 demo，没有记忆，没有工具编排，也没有账号体系。想拿它当「AI 员工」用，会失望。

第二盆：界面免费，聊天不免费。API Key 要自己申请，按量计费。DeepSeek 的价格不算贵，但用量上去了，照样是钱。

第三盆：隐私要自己看住。Key 和设置存在浏览器本地，对话和附件也存本地；但你发出去的每句话、传的每个文件，都会到 API 服务那边。公共电脑别填 key，部署到公网也别把 key 写进代码。

数字与节奏

四个版本，最新 v0.1.3 是 11 月 20 日发的。修的是一个很具体的问题：超大图片会让聊天请求失败，现在长边超过 4096 像素的图，上传前会自动等比缩小。

数据采集于 2026-11-21：星数/fork 16:16，下载量 16:15（四个版本合计）

四个压缩包合计下载 7,835 次。节奏不算快，7 次提交、4 个版本，但每次都在修真实问题。这种「官方小项目」的气质，比很多个人项目稳。

适合谁

如果你想要一个自己的 AI 入口，或者想学一个完整的前端项目怎么搭，这是很好的底座。会一点前端的话，换 logo、改默认模型、加一句欢迎语，半天能弄出个样子。

如果你只是想找个 AI 聊天，装官方 App 更省事。这个项目解决的不是「有没有 AI 用」，而是「这个入口归谁」。

它更像一块地基，不是精装房：住得舒不舒服，看你在上面加什么。

手机宽度下自动换成单栏（官方演示页实截，2026-11-21）

🧰 上手小抄
① 打开 deepseek-ai.github.io/chat-demo，在设置里填 API Key；想本地跑就下 Releases 的 zip，解压后用任意静态服务器打开。
