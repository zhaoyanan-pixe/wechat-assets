地铁上，我对着手机说了一句：「给文件传输助手发条消息」。说完，我继续刷我的视频。

旁边一颗小胶囊亮了一下。对话页右边那条横条里，微信自己打开、找到联系人、打字、点发送。全程我没碰屏幕，也没切换 App。

那块屏，不是我的屏。

一台手机，现在有两块屏：一块在我手里，一块在后台替我干活。

这个 App 叫 Mika，GitHub 仓库 10 月 29 日晚上才建，到今早 3,800 多星，还被 fork 了 700 多次（fork 就是把代码复制一份到自己账号下，相当于「抄回去改」）。作者是 wangzan101，Kotlin 写的安卓原生应用，Apache-2.0 开源协议（允许商用和修改），代码全公开。

官方演示动图：一句话发消息，右边是它在后台屏上的每一步（4 倍速，聊天列表已打码）

它干活，屏幕还是你的

原理说起来不复杂：它借安卓自带的「无线调试」启动一个内置小助手，再打开无障碍服务（这两项是安卓给「自动操作屏幕」准备的官方开关），在一块单独的后台屏上开 App、点按钮、打字、翻页。

所以你在主屏上该干嘛干嘛。想盯着看，对话页里有个小画面实时直播它在点什么；不想看就关掉，只留右下角一颗小胶囊，需要你出手时它会变橙色。

要求也写得很实在：装它安卓 11 就够；要它操作 App 得安卓 12 以上，作者推荐安卓 14 以上，因为后台屏有自己的焦点，不会抢走你打字的输入框。

示意图：一台手机，两块屏（按项目 README「不占你的屏幕」一节整理）

它不接接口，它像人一样看屏幕

这是我觉得最有意思的地方：它不需要任何 App 给它开放接口，也不用事先适配。它跟人一样看屏幕、找按钮、点击输入。

界面读不出来的 App（自己画的控件、按钮没名字）它也能应付：APK 里自带文字识别，读屏上的字；如果配了能看图的模型，还能直接看图找按钮和输入框。

另外它内置了一批「使用知识」，23 个 App 加 18 个网站，写清入口在哪、常见怎么做：微信、小红书、抖音、飞书、知乎、快手、闲鱼、BOSS直聘、领英都在里面。没写到的照样能用，只是要多试两步。

我要泼一盆冷水的地方也在这。这条路线的软肋就是「看」：屏幕一乱、弹窗一多，它就可能点歪。它的补法是每一步都能点开回看，随时能喊停，停了还会交代自己做到哪了。

该停手的时候，它知道停

三件事它一定会交给你：登录、验证码、付款。遇到这类页面，它把 App 挪到前台，发通知请你接管，你处理完交还，它重新核实再往下走。

默认的「询问模式」也很克制：只有花钱（下单、付款）才先问你，发消息、提交、删除这些它直接做完；你要彻底放手，可以切成「自主模式」。

项目 README 里的实拍：一句话，三个岗位都打过招呼，三条消息都显示「送达」

那张截图我看了很久：一句「帮我在 BOSS直聘网页上找岗位打招呼，AI 产品经理，先三个试试」，你先登录一次，它自己搜岗位、筛出三个、发出打招呼，最后汇报「消息列表里三条都显示「送达」」。

外卖那张更有意思：让它凑满减，它一项一项算，减掉哪串、换哪张券，算到 64.78 元（README 实拍），然后停在「立即支付」前面等你。花钱那一步，它不替你做主。

数据不进它的服务器

它没有自己的服务器。你说的话、屏幕上的内容，只发给你自己配置的模型服务商。

API Key 和记忆加密存在手机上，对话和运行记录只留本机，检查更新只连 GitHub。这一点，对在意隐私的人是加分项。

模型随便挑，国内厂商基本都预置了：DeepSeek、通义千问、Kimi、智谱、硅基流动、火山方舟、MiniMax、阶跃星辰、腾讯混元、百度千帆。不想填 Key，也能用 ChatGPT、xAI、OpenRouter 账号登录。

三天 351 次提交，快得有点吓人

我扒了一下它的账：35 个发布版本、351 次提交（一次提交＝一次代码改动）、25 位贡献者、16,219 次下载，最新版 0.1.33 是今天凌晨 2 点 54 分（北京时间）发的。

数据截至 2026-11-02 08:00（北京时间），来源：GitHub API 与 Releases 列表

三天多时间做到这个量级，更新快得有点不像一个人的项目。好处很明显：问题修得勤，你今天踩的坑，明天可能就没了。

坏处也明显：版本号还在 0.1 打头，说明它是早期软件。别把它当成能托付重要事情的稳定工具。要紧的事用询问模式，结果自己核一遍。

它自己在 README 里写了提醒：自动操作第三方 App 和网站，可能违反对方的用户协议。批量打招呼、批量操作这类事，平台风控也会盯。用不用、用在哪，自己掂量。
