上周让它改一段稿子。

第一遍，它把整段重写了；第二遍，只换了个标点；第三遍，把前后两段一起磨平了。

我盯着屏幕想了半天，最后在聊天框里敲了一行：「第三段那句还是太硬，换个说法。」

敲完我自己都笑了：这话它听得懂才怪。

不是它笨。是我在用一个最不适合验收的界面——聊天框。

聊天框只有一个输入行

它写得比你快，这件事已经成立了。真正卡住的地方挪到了下一步：你读，然后说清楚哪里不对。

麻烦就在这儿。你要指的东西，在屏幕上第三屏、第七段、那个表格下面。你能用的工具只有一个输入框，只能拿语言去描述位置：「倒数第二段」「标题里第六个字的说法」。

指一次，往返一次。改五处，聊二十句。到最后你放弃精确，说「整体再自然一点」。

Plannotator 要解决的就是这个。

它干的是一件很朴素的事：把作业摊开

装好之后，当 agent 写完计划、写完文档、改完代码，它会在你的浏览器里开一页，把东西整整齐齐摊开。

你在上面选词、划线、写批注、点发送。批注带着位置，直接回到 agent 手里。

它有分寸的地方在于：你划中的那句话，可以标成删除（不要了）、加一句评论（这儿我不喜欢），也可以直接写一句替换（改成这样）。

旁边还有标红、标记、打标签这些更细的动作。意图分得清，AI 就不会把「我不喜欢这句」理解成「整段重写」。

官方截图（来源：仓库 .github/assets/annotate.webp）：文档里划中一句，批注就写在那句旁边

不只是代码

名字里带 annotate，很多人以为它是给程序员用的。它审的东西比想象中宽。

计划、规格、Markdown 文档；一整个文件夹；任意网址（它抓回来给你批）；还有你本机正在跑的那个网页。不是截图，是真页面：你标在按钮上，页面的热更新照旧生效。

代码那边也能审：本地的改动，GitHub、GitLab 上的 PR，还能让 agent 把一大堆改动切成章节，要紧的放前面。

官方截图（来源：仓库 .github/assets/html.webp）：批注打在真正跑着的网页上，不是在截图上画

我最喜欢的是「收件箱」

一个人用 agent，屏幕只有一个。几个 agent 一起干活呢？问题会撞车。

它的收件箱把这事摊平：几个 agent 把问题、待审的文件、要不要点同意的决定，全丢进一个本地窗口，按「需要你做什么」分组。你有空就答，没空它们继续干，没有一条会话挂在那儿等你。

它 README 这一节里，列了四个能接进来的「个人助手」：Grok Bot、Muse、Hermes、OpenClaw。

Hermes 就是我这套班底底下的那层。看到自己的名字被写进别人的文档，感觉挺奇妙：不是被致敬，是被当成一个「可以对接到的东西」。

官方截图（来源：仓库 .github/assets/inbox-light.webp）：几个 agent 的消息按「需要你做什么」分组，手机上也能答

三盆冷水

第一，它服务的是「用 agent 干活的人」。你手上得有 Claude Code、Codex、Gemini CLI 这一类工具，它靠钩子和插件接进去。只在网页上跟 AI 聊天，这个工具暂时帮不上你。

第二，Windows 上不是每一步都顺。Codex 的原生钩子还是实验性的，安装器只会打印手动步骤；Amp 还得自己拷一个插件文件。团队版（Workspaces）眼下还只有一个排队名单（waitlist）。

第三，安装方式是「从网上下载直接跑」：macOS、Linux 是 curl 管道给 bash，Windows 是一行 PowerShell。介意的人可以只用 --minimal 装一个可执行文件，或者下二进制、核它给的 SHA256 校验和。它的远程模式是在所有网卡上开端口、不要登录，别在不可信的网里开着。

最后说句实话

它的界面谈不上好看，用起来是「工程师做给自己」的手感。

但它盯住的位置很准。

这两年我们在教 AI 怎么干活：怎么写、怎么改、怎么自己想清楚。很少有人认真做「它干完，我怎么验」这一环。

而验收这件事，最缺的不是更聪明的模型，是一块能让你把话指清楚的纸。

你说得清，它才改得对。

🧰 上手小抄
① 装：Windows 打开 PowerShell 跑 irm https://plannotator.ai/install.ps1 | iex；macOS / Linux / WSL 跑 curl -fsSL https://plannotator.ai/install.sh | bash。安装器会自动认你装了哪些 agent，把钩子和命令接好。
② 先试这个：在你的 agent 里打 /plannotator-annotate README.md（或任意 md 文件、文件夹、网址），本地页面弹出来就划线写批注，写完点发送。
③ 小坑：Windows 上 Codex 的自动钩子还是实验性的，安装器只打印手动步骤；不想让它动你的配置，加 --minimal 只装可执行文件。
