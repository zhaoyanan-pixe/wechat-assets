你让 AI 给你做个弹窗，它大概会回你一段 JS：一个 div、一层黑遮罩、监听点击、锁住页面滚动、再算按 Esc 关闭。

这不是哪一家 AI 笨。Chrome 团队在官方博客里写了诊断书：模型的训练数据里，堆满了十年前的代码。

浏览器里现在有现成的写法，几行属性就够。问题在于，没人告诉 AI。

官方文档首页：一句话说明它干的事，下面就是安装命令（来源：developer.chrome.com/docs/modern-web-guidance，2026-11-25 本机实截）

一个给 AI 补课的包

项目叫 Modern Web Guidance，直译是「现代网页指南」。它不是软件，是塞进 AI 编程助手里的一套技能包。

装法一条命令：npx modern-web-guidance@latest install（要 Node 22 以上）。

装上之后，你的 AI 写网页之前会多做一件事：拿关键词去本地资料库里搜一条指南，再照着写。

搜索在本机跑，离线也能用，不调接口，不要 key。

项目今年 1 月建仓，11 月 10 日发 1.0。发 1.0 那天还有件事：Firefox 和 Edge 的团队正式加入。原来是 Chrome 一家，现在是 Chrome、Edge、Firefox 三家浏览器的人一起维护，MDN 文档团队也在列。

到今早 8 点，它 10,813 星。我自己每周统计的那份热度榜上，它这一周涨了 4,400 星，排第二（本号统计，不是 GitHub 官方榜单）。

我本机试了

Windows 10，Node 22.22。我照 README 的例子搜了一句：「给弹窗和遮罩做动画」。

回来 10 条，全是具体做法，不是大道理：点窗外关闭、页面不跟着滚、进出场动画、按 Esc 关闭、不写 JS 也能开关。

挑一条取全文，254 行。里面有一句我看笑了：Firefox 129 以后认这个属性，但实际不生效（官方 bug 编号 1882408）；还有一个属性 Safari 干脆不支持。所以它顺手给了降级写法，连「别把这条写进简写里，老浏览器会整条忽略」都标了红线。

这就是「补课」和「搜一下」的区别：它知道在哪个浏览器上会翻车。

本机实测：一条命令，回来 10 条指南，第 2 条正是讲弹窗进出场动画的那条（2026-11-25，Windows 10 + Node 22.22）

数字有多硬

官方拿 229 个任务、近 2,000 项检查跑了评测。同一个模型，装和不装，差多少？

官方博客那张图：不装，通过率 52%；装了，91%（截至 11 月 9 日）。

README 里还按模型分列（11 月 20 日那一轮）：Codex 49% 到 85%，Claude Code 54% 到 94%，Antigravity 56% 到 97%。

这些检查不是人打分。专家先把「做对了应该长什么样」写成规则，再用自动脚本去验。

官方评测数据：左边整体口径，右边是 11 月 20 日分模型快照（来源：Chrome 官方博客与项目 README 评测表；文档首页另一处把同一指标写成约 51%，取数时点不同）

它到底在纠什么

官方还写了一篇《AI 在网页开发里最容易错的 10 件事》。挑三个你能直接感觉到的。

弹窗：AI 爱自己写遮罩、自己算点击外面、自己锁页面滚动。浏览器早就有 dialog 和 popover，几行属性的事。

滚动动效：AI 多在滚动事件里用 JS 算位置，越算越卡。现在 CSS 能直接驱动。

深色模式：不少 AI 生成的页面，深色模式的用户打开会先闪一下白屏，因为少了一行 color-scheme。

还有一条挺扎心：整套评测里，模型不主动加内容安全策略（CSP，可以理解成给网页装一道防盗门），除非你在话里明确要。按官方原文的说法，就算明确要了，安全检查仍有一半以上过不去。

三盆冷水

第一盆：它只管规矩，不管想法。你让它做的东西本身得说得通，它不会替你想清楚。

第二盆：那个「扫旧代码」的功能（legacy-scan）只覆盖 38 份指南，约全部语料的 20%。我拿一段故意写旧的 HTML 去扫，回来是 0 处。别指望它一键翻新老项目。

第三盆：它会往 Google 发匿名数据。装了多少次、取过哪条指南、搜了什么词，都在里面；原始提示词不收。介意的话，设一个环境变量 DISABLE_TELEMETRY=1 就关掉。

还有一句实话：91% 是官方自己出的考题、自己监考。分模型看是 85 到 97 不等，别当成「稳过」。

本机实测：拿一段旧写法去扫，回来 0 处；它自己注明只覆盖 38 份指南、约两成语料（2026-11-25）

我的看法

它一共覆盖 269 个现代特性：CSS 144 个、HTML 38 个、JS 87 个。官网文档目录的说法是「200 多份经专家审阅的指南」：特性是按能力条数算，指南是按文件算，两个数字不是一回事。

装进 AI 的只有一段很短的说明，约 205 个 token（token 可以理解成模型眼里的字数单位）；包里还带一段 Chrome 扩展开发的说明，约 175 个，也不占地方。

支持面铺得挺开：官方博客点名了 Claude Code、Codex、Cursor、Copilot、WebStorm、Antigravity、Kimi Code、Grok Build；README 里还给了 Vercel、GitHub CLI 和 Pi 的装法。

官方图：能直接装这套技能的编程助手（来源：Chrome 官方博客 2026-11-10）

用不用，判断很简单：你只是偶尔让 AI 做个页面，装不装差别不大；你要长期用 AI 做网页、又不想每次验收都挑毛病，这个包能省不少回头改的时间。

AI 会写网页，早就不稀奇。稀奇的是写得像 2026 年的人写的，而不是像 2016 年的教程抄的。
