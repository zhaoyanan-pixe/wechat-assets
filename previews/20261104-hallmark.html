今天上午，我把一张「标准的 AI 生成网页」丢进一个检查器，想看它能挑出多少毛病。

结果比我预想的重：31 条不合格。

那张页面是我照套路拼的：紫蓝渐变、渐变大字、标题上方一行小字、一句「Trusted by 500+」、结尾一个订阅框。人眼扫过去，只会觉得「还行，有点眼熟」。检查器一眼就把它拆了。

它叫 Hallmark，本周 GitHub 周榜第一。截至今天上午九点，4.7 万星。

它不是模板，是「别这么干」的说明书

Hallmark 是给编程 AI 用的一份设计技能，Claude Code、Codex、Cursor、OpenCode 都能装。作者是 Together AI，MIT 协议（可自由使用、修改、商用），代码主体是 CSS。

别误会，它不是一键建站工具，也不是网页模板。装上之后，AI 做页面前会先做五件事：

  • 先问素材：真实照片、真实截图、真实数字。问一次，没有就留空，不许编。
  • 再挑材料：它有 50 套主题，每套是一份不超过 8KB 的文件，配一张成品页图。系统按你的任务抽 3 套，给你挑。
  • 再定结构：预约页要能约、商店要能卖、订阅页要能订。页面放什么、按什么顺序，不是模板说了算，是「访客来这儿要干什么」说了算。
  • 然后只做首屏：先把第一屏做出来、渲染，让一个「没有上下文」的评审员冷眼看一遍，过了才往下做。
  • 最后在真浏览器里按 8 种宽度跑一遍检查。

官方宣传图，三个不同主题做出来的首屏（来源：github.com/Nutlope/hallmark）

那些「一眼假」，原来都有名字

我最喜欢的，是它把「AI 味」写成了一份能机器检查的清单：

  • 标题上方那行小字（eyebrow），就是「关于我们」上面那句；
  • 字距拉开的全大写小标签，TRUSTED BY… 那种；
  • 标题里只给一个词上色；
  • 整页空框，或者整页照片；
  • 首屏在手机上被裁掉一半；
  • 每页结尾都塞一个邮件订阅；
  • 表单点了「提交」直接说「谢谢」，背后根本没有接口。

这七条不是审美争论，是能被 CSS 和页面结构查出来的东西。能查，就能拦。

七条「一眼假」，每一条都有名字（来源：项目 README）

也正因为这个，它的观感不靠「好看」撑着。同一套规则，能做出完全不同的四种气质：

四个官方主题示例：同一套规则，四种气质（来源：docs/screenshots）

三级闸门：39 条不许商量，50 条可以讲理

我把它的闸门清单（gates.md 第 4 节）一行行数了一遍，一共 90 条：两档，外加一条只记账的。

Floor（地板）39 条，永不放过：紫到蓝的渐变、纯黑纯白、卡片套卡片、编造的数字、假表单、「Learn more →」这种模板标点、拿 emoji 当图标。

Reflex（惯性）50 条，是模型自带的毛病：标题里染一个词、整页只用一种灰。你有真理由，可以在代码注释里写一条「豁免」；同一个毛病连续三版都豁免，它就认为那是你的风格，让你写进项目规范。

第三档 Finish（工艺）不在这 90 条里，是第 5 节另列的 26 条细节，只报告、不拦发布。凑近才看得出的东西，写上理由就算「回答过」。

两档闸门 + 一条记账；Finish 另计（按 gates.md 第 4、5 节统计，2026-11-04）

我给它喂了一张反面教材

我按 AI 网页最常见的套路拼了个测试页：渐变底、渐变大标题、眉标、全大写字距标签、三个形容词用圆点串起来、一句编出来的「10x faster」。

然后跑它的检查器 sloplint。零依赖，Node 18 就能跑。

输出是 31 条 FAIL、4 条 REFLEX、5 条警告。被点名的几条挺具体：

  • buzzword「Supercharge」：标题里的「超级加速」，属于套话；
  • eyebrow「AI-Powered Platform」：标题上方那行自我介绍，直接判删；
  • middle-dot meta string：用「·」把几个形容词串成一行的写法；
  • uppercase tracked 0.18em：那行小字的字距拉得太开；
  • metric「10x faster」：这个数是你自己编的，请拿证据。

它对自己的规矩也不手软。我的测试页没在 CSS 第一行写它的「印章」（一段自评：六个维度打分、点名最弱项，再交代这页的几个决定），照样记一条 FAIL（gate 20）。

本机实测输出：31 FAIL / 4 REFLEX / 5 WARN（2026-11-04）

一句话总结这次实测：一张按套路拼出来的 AI 落地页，31 条不合格，其中 4 条可以书面申诉，5 条只是提醒。

有件小事，我得承认

它的规则里禁破折号。gate 19 把长破折号和短破折号一起列进了文案套路。

我看到这条的时候笑了一下，因为我写稿最爱用它。

所以这篇我数着用，一次都没用。你读到这儿，应该没觉得少了什么吧。

装不装都行，先让它审一遍

装：npx skills add nutlope/hallmark -g，需要 Node 18 以上。装完在 Claude Code 里打 /hallmark，或者直接说「用 hallmark 做这个页面」。

不想装也能用。仓库里那个 sloplint 可以单独拉出来跑：node skills/hallmark/scripts/sloplint.mjs 你的页面.html。静态规则不用浏览器；加 --render 才会开 Chrome 量 8 种宽度，还得先装 puppeteer-core。

/hallmark audit 路径 只报告不改动，适合先看诊断。redesign 会先把原来的链接、字段、标题记下来，改完少一个就算失败。

两个提醒

一，它的规则是英文语境的。被点名的词是 seamless、supercharge 这类英文词；换成中文「无缝」「赋能」，它认不出来。中文页面想用，得自己补一套词表。

二，4.7 万星不等于你就该用。这套东西的审美是编辑感、克制、纸感，它反对的东西里，有些正是不少甲方偏爱的（大渐变、发光字、满屏大图）。它把「别像 AI」写成了硬标准，不是把「好看」写成了标准。

🧰 上手小抄
① 装：npx skills add nutlope/hallmark -g（Node 18+）；只想体检，就单独跑 sloplint。
② 先试这条：对现有页面跑 /hallmark audit，只报告不改动，先看 Floor 有几条。
③ 一个坑：它认英文，中文里的「无缝」「赋能」查不出来，别把「没报错」当成「没问题」。
