我在一个卖可颂的网站上逛了半天。

限量款手表、防水帆布包、现烤可颂、松饼，加购物车、填地址、选配送，一整套都齐。

直到我点开导航栏的「Themes」，换了个主题名：整家店从冷淡黑白，一下变成黄油色；再点，成了抹茶绿。

那家店其实不卖任何东西。它是 Meta 设计系统 Astryx 的官方演示站，专门用来看「同一套组件，换七套主题，气质能差多远」。

官网首屏实拍（来源：astryx.atmeta.com，2026-11-18 截取）：标题下面就是那家用来演示主题的假商店

这东西在 Meta 内部长了八年

Astryx 不是新做出来的玩具。

它在 Meta 内部用了八年，成了公司里最大、用得最多的设计系统，撑起 13,000 多个应用。工程师、设计师、产品经理，天天拿它拼界面。

今年 1 月 9 日，仓库放上 GitHub，MIT 协议，谁都能拿去商用。

这周它突然冲上我们每周统计的那份热度榜第一：七天涨了 13,660 星，总数三万多。

（这份榜单是我们自己扫 GitHub 全站排出来的，不是 GitHub 官方排名。）

它这波热度，和 11 月 14 日的一条公告对得上

11 月 14 日，Astryx 团队发了篇很短的公告：Astryx 进了 v0。

v0 是 Vercel 的 AI 建站工具，你打一句话，它给你搭出能跑的网页。现在在 v0 里选 Astryx，这套设计系统的规矩、组件、示例、模板，会跟着进到 AI 的上下文里。

官方那句话说得挺直白：在 v0 里，一个设计系统就是一个 agent 技能。

翻成白话：以后 AI 给你搭页面，不再凭它自己的喜好摆，而是照着 Meta 内部那套规矩来。

公告是 11 月 14 日发的，我们的周榜统计截到 11 月 15 日，时间挨得很近。

不过得说清楚：这 13,660 是整整七天的累计，公告只赶上最后两天，不能全算在 v0 头上。两件事摆在一起，你自己判断。

本号自制卡：在 v0 里，设计系统以「技能」的形式进到 AI 的上下文（依据：官方博客 11-14）

为什么我觉得这比「又开源一个库」重要

AI 现在最不缺的，就是「能画出个看着像样的界面」。

Astryx 团队自己在博客里写了：AI 已经能生成看起来很像的界面，但看起来像，不等于好用。

他们做的事，是把「什么叫好用」写成 AI 也读得懂的说明书：同一套接口、同一份文档、同一个命令行。人查的是这份，AI 查的也是这份。

他们还有一句我很喜欢的话：每一项让 Astryx 对 AI 更友好的改动，也让人用起来更顺手。

说白了，设计系统以前是给人看的规矩，现在得写成机器也认得的规矩。这一步，比多几个组件难得多。

它到底给了什么

组件 150 多个，从按钮、表格、日历、聊天输入框，到空状态、骨架屏，全带 TypeScript 类型（写代码时编辑器会提醒你参数对不对）。

页面模板分了十类：仪表盘、表格、表单、设置、登录、工具、内容、AI 聊天、画廊、外壳。

主题七套，名字像奶茶菜单：neutral、stone、gothic、matcha、y2k、butter、chocolate。

主题不是「改配置」。一套主题就是一组 CSS 变量（页面上所有颜色的集中设定），一条命令抄进你自己的项目里改：npx @astryxdesign/cli theme add neutral。

还有个功能叫 swizzle。某个组件你想改内部结构，它不给你留个口子调参数，而是把那个组件的完整源码整个抽到你项目里，从此这份代码归你改。

代价也明摆着：抽出来那天起，上游修 bug 跟你这份没关系了。

主题页实拍（来源：astryx.atmeta.com/themes，2026-11-18 截取）：在这里换主题名，预览区整家店跟着变

三盆冷水，外加一句实话

第一，它还在 Beta。版本号 v0.7.16，光 11 月 10 日到 14 日这几天，就发了五个版本，接口随时会变。

第二，它要 React 19。不写代码的人，只能在演示站里点点看，改不了任何东西；只做静态页面的，也用不上。

第三，社区热得有点吓人：仓库里六百多个 PR 排着队没合，三百多个 issue 开着。有人气是好事，另一面是维护团队接不过来，你提的需求未必轮得到。

再说句实在话：它的长相是 Meta 那种实用派，干净、规矩、克制。想要「一眼惊艳」的模板站，它不是。

我最在意的，是它给出的信号

数字上它确实热：npm 上核心包上个月下载 219 万次（10 月 18 日到 11 月 16 日，npm 官方接口）。

但我更在意的是另一件事。

这两年我们看惯了「AI 能做出一个网页」。接下来要看的，是「AI 做的网页，能不能直接用」。

能不能直接用，靠的不是模型再聪明一点，是底下有没有一套说得清的规矩：间距多少、颜色几档、按钮什么状态、出错怎么提示。

Meta 磨了八年，现在把这套规矩交到 AI 手里。

这件事，比多一个组件库有意思得多。

🧰 上手小抄
① 先看：打开 astryx.atmeta.com，Themes 页点主题名切换，Sandbox 里一个个试组件，不用装任何东西。
② 要用：项目得是 React 19，装 npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex 和 npm i -D @astryxdesign/cli；再用 npx @astryxdesign/cli theme add neutral 把主题拷进自己项目改（README 建议在 package.json 里加一条 astryx 脚本，免得直接调 CLI 时路径报错）。
③ 提醒：还在 Beta，版本号跳得快；它在 v0 里那套要先有 Vercel 账号，国内访问得先解决网络。
