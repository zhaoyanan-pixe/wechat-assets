我最近老想起一个画面：人在地铁上，AI 在家里的电脑上改代码。

上周这个画面有了现成的工具。一个叫 T3 Code 的项目冲到 GitHub 周榜第一，一周涨了 1.7 万星，总共 5.2 万。

它干的事一句话能说清：把你电脑上已经装好的 AI，接到手机、网页、另一台电脑上。

仓库挂在 Theo 的公司 Ping.gg 名下。他不是无名之辈，官网首页挂着一条留言：「我最喜欢的界面，是一个 YouTuber 和一个叫 Julius 的瑞典人做的」。

数据也对得上：提交最多的是 juliusmarminge，3,980 次；作者 t3dotgg 自己 1,072 次。

官网首屏实拍（t3.codes，2026-11-09）：右上角写着 52k+ GitHub stars

它不生产 AI，它给 AI 装了个驾驶舱

T3 Code 自己的说法是「智能体控制台」。翻成人话：它不聪明，也不卖模型，你电脑上得先有一个能干活的 AI。

README 里列了七家：Claude Code、Codex、Cursor、Grok Build、OpenCode、Antigravity、fx。装好、登录，T3 Code 就把它们接进同一个界面：左边会话列表，中间对话，底下是文件改动。

文档里还藏了两个实验性的：Pi 和 Muse Code。

官方 FAQ 里有个比喻很贴切：AI 是厨师，harness（驾驭 AI 的那层外壳）是厨房，T3 Code 是那家「允许你自带厨房」的餐厅。

它靠什么赚钱？不赚。官网原话是「Nothing. There's no way to pay us.」，没有让我们收你钱的办法。MIT 协议，代码全给。

节奏也猛：稳定版到现在才 0.1.7，但几乎每六小时就推一个 nightly 构建，11 月 8 日一天推了三个。

自制卡：一周涨了多少（数据来源见图内，截至 2026-11-09 08:02）

手机怎么找到家里那台电脑

这是我觉得最实用的一段：不用公网 IP，不用动路由器。

电脑端打开「设置 → 共享与访问」，登录、开启 T3 Connect；手机 App 登同一个账号，那台机器就出现在列表里，点进去接着聊。

免费账号能连 3 台机器，手机和浏览器不算名额。同一局域网直连、Tailscale 也支持。

当然有前提：电脑得开着，也得联网。它不是魔法，只是把「你必须在电脑前」这条约束去掉了。

Google Play 官方应用截图：左边是电脑列表，右边是直接在手机上审改动（来源：Google Play，2026-11-09）

真正值钱的是「拍板」

T3 Code 有四档权限，从紧到松：

  • 逐条批准：改文件、跑命令都要你点一下；
  • 自动改文件：改代码不用问，跑命令还得问；
  • 自动：交给服务商自己审，拿不准再问你；
  • 全放开：什么都不问。

注意最后一档：新会话的默认值就是「全放开」。第一次用，我建议先切到「逐条批准」。

会干活只是及格线。会用手机通知把你叫回来拍板，才是它省事的地方：AI 干完了、失败了、卡在等批准，手机上都会弹一条，点开就是那个会话。

手机端还有个细节：iOS 是「实时活动」，Android 16 以上是「实时更新」，锁屏上挂一条进度，干完之后结果还留 15 分钟。

自制卡：四档权限，新会话默认是最后一档（来源：官方 permission-modes 文档）

不好听的部分也得说

它非常早期。作者在 README 里写得很直白：「我们在非常非常早期，做好遇到 bug 的准备」，还补了一句「暂时基本不接受外部贡献，小修可以考虑，大功能不行」。

数据也印证了：截至今天早上，仓库里有 1,987 个没关闭的 issue、3,969 个待合并的 PR。这个量级说明，想帮忙的人比维护的人多得多。

还有三件得知道：

  • 默认权限「全放开」，等于把电脑交出去一部分；
  • 官方 FAQ 自己承认：走 Anthropic 的 Agent SDK，会更快耗掉 Claude 的 5 小时额度。作者说这是 Anthropic 那边的问题，已经报过去了；
  • Windows 上还做不了后台常驻，得留一个终端窗口开着。

官网首页倒是挂了句自嘲，我挺喜欢：「Tolerated by over 500,000 devs」，被 50 万开发者「容忍」。

自制卡：手机连到电脑的三条路（来源：官方 remote-access 文档）

所以要不要用

我的判断是：它不给你多一个 AI，它让你离得开电脑。

为什么不直接用 Cursor，或者 Claude、Codex 自己的桌面版？官方 FAQ 的回答很直接：订阅还是你自己的，远程和手机是它最强的两块，而且 100% 开源，哪天走偏了，你可以 fork 一份带走。

适合的人：已经在付 Claude 或 Codex 订阅、又经常不在电脑前的人。钱不变，只是换了个地方指挥。

不适合的人：还没开始用这些 AI 的。它自己不产生能力，装上去也是空的。

🧰 上手小抄
① Windows：先在终端装好并登录一个 CLI（比如 Claude Code），再在 PowerShell 里跑 irm https://t3.codes/install.ps1 | iex，或者 winget install T3Tools.T3Code；敲 t3 启动。
② 想在外面用：桌面端「设置 → 共享与访问」登录并开启 T3 Connect，手机装 T3 Code 登同一个账号，就能看到那台电脑。
③ 提醒：默认权限是「完全放开」，第一次先切到「逐条批准」；项目很早期，别拿它碰重要仓库。
