上周，我把一份活动方案丢给 AI，让它帮我看看有没有问题。

它回得挺客气：整体思路清晰、结构完整，还能再补充两点细节。

我改了两句，发出去了。

对方回的第一句话是：「这个谁负责？」

我翻回文档，从头看到尾。真没写。

AI 也没提。它列的那两点细节，一条都不沾这个。

不是它笨。是它太熟。

它记得我前面怎么解释这个活动、为什么定在周末、哪些事「不用说它也懂」。

于是它拿着我的框架，看我的东西。我看不见的地方，它照样看不见。

一个记着，一个专门忘掉

Google 两个月前开源了个工具，就叫「大象与金鱼」（Elephant-Goldfish Model）。

1.9 万星，今年 9 月 13 日建的仓，到今天 64 天。

分工一句话说清：大象记着项目背景，负责把方案起草出来；金鱼没有记忆，只拿你的文档和它引用的材料，冷眼挑刺；你负责拍板。

本号自制卡：三个角色各管一段（依据：项目 README 的角色表）

金鱼这点不是比喻得好看。它的审稿人必须跑在一条全新的、不带任何历史对话的子会话里。

开不出来，它宁可当场停下，也不在同一段对话里假装审过。

它挑刺，挑到什么程度

官方首页摆了个例子，我觉得比任何功能介绍都直观。

一份「学习空间开放计划」写着：3 月 3 日开放；志愿者在开放时间内值守；学生用平常那张表订房间；按周五的规矩来。

读着挺完整，对吧。金鱼读完，只问三句。

谁值守？文档里没有人名，也没有排班表。

开放时间是几点到几点？它写了「开放时间」四个字，就是没说几点。

周五的规矩又是什么？这条依赖一个读者根本看不到的决定。

官方把这事总结成一句话：作者知道一些文档里没写的事；只有没参与过那场对话的人，才找得到那些洞。

官网首屏实拍（来源：egm.dev，2026-11-16 截取）

这话不只对 AI 成立。找人看方案，最没用的是全程在场的同事：你说的他都懂，会顺手替你补上。

一份文档，过五道关

它也不是「再问 AI 一遍」这么随意。一次审稿要走五关，每关换不同的人上。

本号自制卡：五个阶段与各自的审稿人（依据：skills/egm-review/SKILL.md）

我数了下仓库的角色目录：10 个角色文件，2 个负责调度汇总，其余各管一关。

第二关最有意思：给一个「什么都不懂的新人」看文档，而且刻意不给任何背景材料，只给文档本身。术语、缩写、没定义的东西，一律挑出来。

五关走完还有收尾：所有意见汇成一张表，按 🔴 拦路 / 🟡 重要 / 🟢 小毛病 三级排好，再交回你手上。

每关只允许复核一次。你想再磨，它会告诉你到顶了，剩下的记成「你接受的取舍」，然后往下走。

最狠的不是流程，是那 11 条规矩

我翻它给审稿人写的说明书，看到一段不太像 AI 会写的话。

本号自制卡：审稿人行为规范摘 5 条（英文为原文，中文为本号译述）

一共 11 条执行约束。禁止嘴甜、先批评后肯定、不许当回音壁、被质疑时不许道歉、不许在聊天窗口里糊一大段草稿（必须写进文件里让你打开看）。

你想想，我们用 AI 最舒服的地方是什么。就是它嘴甜。你说什么它都「这个思路很好」「这个方向很有价值」。

这个项目把「讨好」当成 bug，写进了规矩里。

我不敢说它多聪明。它做的事，说穿了就是把「换个没被污染的人再看一遍」写成了流程加纪律。

我不敢把 1.9 万星都算在这几条规矩上。但方向肯定没错：能挑刺的 AI，比只会点头的 AI 值钱。

不写代码也能用，但先泼三盆水

官网第一句就写着：EGM 作为插件跑在这些应用里，你不需要写软件。

它明确说可以拿去审班级项目、设计需求、交付计划、软件设计。官方那套「起草 → 审」的流程只面向软件规格；要审别的文档，换 /egm-review-loop，自己挑审稿人和标准。

支持的客户端：ChatGPT 桌面版、Codex、Claude Code、Claude Cowork、Antigravity，另有 omp 和 Muse。

第一盆水：官网页脚有一句「这不是 Google 官方支持的产品」。仓库挂在 Google 组织下，是开源的，但别当成 Google 出品的产品来依赖。

第二盆水：版本号还停在 0.1。10 月 27 日第一个发行版，11 月 6 日第二个；72 个 issue（用户提的问题单）开着，另有 39 个 PR（待合并的修改）在排队。

第三盆水：客户端得能开独立子会话。Antigravity 的独立 IDE 版明确不支持，跑了会直接停。

还有一层我没实测：它的审稿说明书要求用「简单直白的英文」写报告。中文文档能不能审、报告会不会全变英文，我不敢替它保证。

作者自己倒是写了一句实在话：审稿不能替代测试，也不能替代人。

大象记得住，金鱼忘得掉

我们总说 AI 是同事。

同事最值钱的能力，真不是替你把活干完。

是在你按下发送之前，敢说一句：这块你没写清楚。

大象记着背景，金鱼负责忘掉，人负责拍板。

这套分工，比「再问它一遍」靠谱得多。

① 装：Claude Code 里两条命令——claude plugin marketplace add google/elephant-goldfish-model，再 claude plugin install egm@egm；Codex 用 codex plugin marketplace add google/elephant-goldfish-model 加 codex plugin add egm@egm；Antigravity 用 agy plugin install https://github.com/google/elephant-goldfish-model；ChatGPT、Codex 桌面版直接装官方插件页。装完重开一个会话。
