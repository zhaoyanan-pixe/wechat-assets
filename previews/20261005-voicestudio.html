先说个数字：16,775。过去一周，有 16,775 颗星落在同一个项目上——直接把它送上了 GitHub 周榜第一。

它叫 VoiceStudio。干的事一句话能说完：把一整套「AI 声音工作室」，搬进你自己的电脑。

具体点：一段 3 秒的录音样本，能克隆出一个可用的声音；一段视频，能换成另一种语言开口说话；再加上有声书、听写、转写……以前要凑一打云服务才齐的活，它一个桌面应用全包——而且，声音全程不出门。

有点意思的是它的站位。AI 配音里名气最大的 ElevenLabs，好用归好用，但那是云端：按月订阅，声音得先上传。VoiceStudio 的想法正相反——官网第一行就写着：开源的、完全本地的替代品。

它也不算横空出世：仓库今年 4 月就建好了，安静打磨了半年，这周突然被推到了所有人眼前。

三秒克隆，一句话设计

先说「克隆」。门槛被压到了多低？官方口径：一段干净的 3 秒样本，就能复刻出一个可用的声音——之后你写什么，它就念什么。

不想用任何人的录音也行。它有个「声音设计」：你用一句话描述想要的声音——「低沉、微哑，像深夜电台主持人」——AI 当场给你造一个。不用找素材、不用借谁的声音。

克隆也好、设计也好，做出来的声音能干嘛？最直接的：把你写好的稿子念出来——不想露脸的口播、要批量读的稿子，都省了。还有现成的「声音画廊」，挑一个直接用。

官方截图：克隆工作台——选一个声音、输入文本，就能生成（来源：项目官方仓库）

把配音做成了一条流水线

克隆只是开胃菜。真正让我停下来的是「视频配音」：一段视频丢进去，换成另一种语言说——带时间轴，每句话卡在原来的位置上，不用你一句句手动对轨。

给你个画面：做视频，你只管拍。后期的「嘴上活」——旁白、多语言版本——它在你电脑里默默跑完；一条中文视频想发英文版，不用找人重新录。

往外还有一串：故事模式——一份剧本，每个角色配一个声音；有声书——一本书进、一章章出；转写——音频进、可搜索的文字出；外加一个浮窗听写，挂在屏幕边上，你说话它记字。

看出来了吧？这套组合拳瞄的不是「好玩」，是干活——做视频的、做课程的、写书的都用得上。官方说，这些工作流覆盖 646 种语言。

官方截图：视频配音工作台（来源：项目官方仓库）

全在你自己电脑里跑

开头说「声音不出门」，具体点讲：不用注册账号、不上传任何东西。它只在两件事上联网——检查更新、下载模型。官方原话很实在：「你的声音，你的工作流。」没有积分、没有额度、没有月底账单——它压根不在那套体系里。

门槛也不高：约 8 GB 内存就能起步；有 N 卡或苹果芯片能快些，没有独显用 CPU 也能跑，就是慢一点。代价是装环境时占地方——纯 CPU 版大约要 5 GB 磁盘。

价格呢？桌面版开源、免费（AGPL-3.0 许可）；想要商业条款的团队，官方另有付费的 Pro 版。一句话：免费是认真的，边界也摆得清楚。

连「装软件」，都能交给 AI

最「2026」的细节在这儿：官方给了一段安装提示词——复制，丢给你的编程助手（Claude Code、Codex、Cursor 都行），它会自己查硬件、装好、再跑一次试生成。装软件这件事，现在可以外包给 AI 了。

它还给 AI 留了正门：本地 API + MCP——可以理解为「给 AI 助手用的标准插口」。意思是，你自己的 AI 助手能直接调用这台「声音工厂」：你让它给视频配旁白，它就在你电脑上把声音生成好。数据，始终没离开这台机器。

官网首屏实拍：免费、开源，Windows / macOS / Linux 全平台（截图于 2026-10-05）

两件事，得说清楚

第一件是红线：克隆声音，必须经本人同意。官方在可用规则里写得很硬——冒充他人、搞诈骗，一律禁止。这条不客套：声音像指纹，是一个人最像「自己」的东西；拿它越界，一点都不好玩。

第二件是耐心：它还是个年轻项目——最新版 0.5.6，9 月下旬才发布。0.x 的版本号意味着迭代快、也可能有小磕碰。尝鲜没问题，先别把它当「生产线」用。

往大了说，「AI 在哪儿跑」正在重新变成一件要紧事：云端买的是方便，本地换来的，是踏实。

最后说点感受。这个项目最打动我的不是功能列表，而是它站的位置：AI 能力正在从「按月租」，一件件搬回你自己的电脑——前几天是 Office、是 AI 员工，这回，轮到了声音。

也许用不了多久，咱每个人的电脑里都会住着一间小小的「私人工作室」。想想还挺让人期待的。
