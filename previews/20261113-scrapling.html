昨晚想给一篇行业报告找原始出处。网页在浏览器里摆得清清楚楚，换成程序去抓，回来只有一行字：请验证您是人类。

这一行字，大概是所有抓过网页的人共同的敌人。看得见，抓不到；换个网站，选择器得重写一遍；网站一改版，昨天还能跑的脚本今天全是空的。

这周 GitHub 上被重新抬起来的，是个两年前的项目：Scrapling。今早八点我查了一眼，10.2 万颗星、1 万多个 fork（别人复制出去改的版本数），BSD-3 协议，Python 写的。11 月 9 日那周的 GitHub 趋势榜上它排第 3，一周涨了 8,712 星。

2024 年 10 月建的项目，怎么现在才火？

AI 缺的不是脑子，是手

今年涨得最猛的开源项目，越来越多是「手脚」这一类：会开浏览器的、会管代码分支的、会审代码的。AI 早就学会写字了，可它还不会登你的账号、不会替你翻完几百页网页、不会等那个转圈圈的验证。

Scrapling 正好长在这条缝里。它自带 MCP 服务器和 Agent Skill，说白了就是让 Claude、Cursor 这类工具直接把它当工具调，抓页面这件事不用你另写一堆粘合代码。

官方仓库头图（来源：Scrapling 仓库 docs/assets/cover_dark.svg）

仓库里那句定位写得很直白：从一次请求到整站爬取，一个库全包。

四件事，塞进一个包

按 README「What you can do with Scrapling」四类能力整理

抓：普通页面走 HTTP，要跑 JavaScript 的换真浏览器；带浏览器指纹伪装，官方说能过 Cloudflare 的 Turnstile 验证和过渡页。

取：CSS、XPath、文字、正则都能选。这里有个我特别喜欢的细节，叫自适应元素追踪——网站改版、class 名换了，它能靠元素之间的相似关系把原来那段找回来。写过爬虫的人知道这有多救命。

爬：并发、按域名限速、代理轮换、断了能接着跑。它会自己看对方的响应速度调整间隔，被限流就放慢，缓过来再提速。

喂：一行 page.markdown() 把整页转成干净 Markdown，直接能塞给 AI 读。

我今早真跑了一遍

装它分两步：先 pip install "scrapling[shell]" 装包，再跑 scrapling install 把浏览器组件下下来。

本机实测记录：两条命令、真实返回码与输出字节数（Windows 10，2026-11-13 08:05）

第一条把练习站的 10 条名言抓成 Markdown，3,190 字节；第二条加了 --css-selector，只留 python.org 首页那一段简介，87 字节。3.47 秒和 2.99 秒，其中一大半是启动开销，不全是抓取时间。

得说清楚一件事：Cloudflare 那一关我没实测。我测的两个都是公开静态页。过验证这事，我现在只有官方的说法，没有自己的证据。所以这篇里凡是涉及它的，我都写「官方称」，不写成实测。

快是真快，但别看错数字

官方解析基准：同一棵 5,000 个嵌套元素的页面树，单位毫秒，越短越快

官方给了组对比：同样这棵树，它 1.99 毫秒读完；最快的对照组 Parsel（Scrapy 用的解析器）2.06 毫秒；老牌 BeautifulSoup 配 html5lib 要 3,412 毫秒，差了 1,700 多倍。

但这组数字量的是「读已经下好的网页」，不是「把网页下下来」。抓取本身快不快，看的是对方服务器和你的网络，跟它没关系。这两件事在宣传里经常被混着说，我先点一下。

官方文档站首屏实截（scrapling.readthedocs.io，2026-11-13 08:03）

三个坑，先替你踩了

一，pip install scrapling 只装了解析引擎。我第一次就栽在这：import 抓取模块直接报错找不到。要用抓取，必须装 scrapling[fetchers] 或 scrapling[shell]，还得另跑一次 scrapling install 下浏览器，几百兆。

二，它有个「开发模式」：第一次跑把网页缓存到本地，之后调解析逻辑就不用反复请求人家服务器。改脚本的时候打开它，又快又体面。

三，能过验证，不等于可以乱抓。项目自己带了遵守 robots.txt 的开关（robots_txt_obey），默认是关的。我建议你打开。抓公开数据、控制频率、别碰要登录的私人页面——这条对所有抓取工具都成立。

🧰 上手小抄
① 装：pip install "scrapling[shell]" → scrapling install（这一步下浏览器，几百兆，等一会儿）
② 先试：scrapling extract get 网址 结果.md，不写一行代码就能把整页存成文档
③ 提醒：robots.txt 开关默认关着，抓之前想清楚；只有要跑 JavaScript 的页面才开浏览器模式，别一律上重的
