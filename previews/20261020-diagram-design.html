上周做一页汇报，我让 AI 画张架构图。

十秒，图来了：圆角矩形、灰色阴影、箭头从框边上歪出来。

我盯了三秒，关掉，打开 PPT 自己画。

不是我难伺候。那种图太有辨识度了，一看就是 AI 画的。

模型也不是不懂内容。你说「前端、后端、数据库、缓存」，它全听懂了。

它缺的是另一样东西：什么叫好看。

项目主页。简介里写着「No shadows. No Mermaid slop.」，态度很直接（来源：GitHub 仓库页，2026-10-20 截图）

有个叫 Cathryn Lavery 的设计师，把这件事想明白了。

她没做画图软件，而是把「审美」写成一份说明书，做成给 AI 用的技能包。

项目叫 Diagram Design。今年 4 月开源，现在 5.8 万星；周榜上，它一周涨了 8,382 星。

先教 AI 一条规矩：能删就删

README 里有句话，我很喜欢：

最高级的动作，通常是删。

每个节点都得有存在的理由；强调色只留一个，给最重要的那一两件事；线用 1px，阴影一律不要；所有坐标落在 4px 网格上。

听着像设计师的碎碎念，但它被写成了 AI 能执行的规则。

所以出来的图，干净得像杂志内页。

我翻了它官方给的几十张示例：架构图、四象限、手机拆解、像地铁线路一样的时序图。风格是同一个人，但每张都有自己的重点。

官方示例：内容网站的架构图。红色只留给一个焦点，其余全退到后面（来源：项目官方示例页）

45 种图，先报方案再动手

45 种，从流程图、时序图、组织架构、甘特图，到四象限、桑基图、鱼骨图、用户旅程。每种还有浅色极简、深色极简、杂志编辑风三个静态版本。

用法很简单：跟 AI 说人话。

「帮我画一张内容网站的架构图：前端、后端、数据库、Redis 缓存。」

它会先把方案说一句：用哪种图、什么尺寸、哪些细节要砍。你在，它等你点头；你不在，它画完把假设标在旁边。

输出是一个 HTML 文件，双击就开；图是内嵌的 SVG，也能直接导出 PNG 或 SVG。

要改，跟它再说一句。

官方示例：影响力 vs 投入四象限。哪个先做，位置自己会说话（来源：项目官方示例页）

它连你公司的颜色都管

还有个小功能，我觉得挺妙。

你给它一个网址，它会去抓你网站的配色和字体：背景色当纸，正文色当墨，按钮色当强调色，连标题字体、正文字体、代码字体都记下来。

之后每张图，自动长成你家的样子。

它还会检查对比度：文字和背景不到 4.5:1，就提醒你换个深一点的颜色。

这一点，很多人类设计师都会偷懒。

对做内容的人来说，这个功能省事：不用每次出图都重新调色，图和你文章、网站是一套视觉。

官方示例：手机拆解图。真实拆机有几十个零件，图里只留四个（来源：项目官方示例页）

说点不好听的

它不完美，作者自己在 README 里写了两条：

一，出图质量看你用的模型；同一句话，两次排版可能不一样。

二，它给不了能拖拽的画布。要改结构，得让 AI 重画；那种存在 Git 里、每个迭代都要改的文档，还是 Mermaid 更合适。

连官方口径都没统一：README 正文写「编号 01 到 44」，画廊已经排到 45，仓库简介还挂着 44。

但我觉得这反而真实。一个知道自己边界在哪的工具，比满屏「吊打」的靠谱。

谁该用

如果你经常做 PPT、写报告、画方案，或者要跟别人解释「这东西是怎么跑起来的」，它值得放进工具箱。

我自己的用法很直接：写文章配图、做汇报的框架页、给不懂技术的朋友解释一个系统怎么运转。

支持的客户端一大串：Claude Code、Codex、Cursor、Copilot、Gemini CLI、Cline、Windsurf 等。

安装就一行命令，MIT 协议，免费。

但它不是给纯小白双击安装的软件，得先有一个能装技能的 AI 工具。没有的话，先从 Claude Code 或 Codex 用一个。

58,390 星、45 种图、3 个版本、6 个月（数据：GitHub API、项目 README；本号制图）

我越来越觉得，AI 的能力涨得很快，品味却没跟上。

模型可以越换越大，品味得靠人一点点写下来。

这个项目做的事，说穿了就一句：把设计师脑子里那些说不清的东西，翻译成 AI 听得懂的规则。

以后 AI 画的图能不能见人，可能就差这一份说明书。

🧰 上手小抄
① 怎么装：先有一个支持 Agent Skills 的 AI 工具（Claude Code、Codex、Cursor 等），在终端跑 npx skills add cathrynlavery/diagram-design。
② 最值得先试：让它画「影响力 vs 投入」四象限，先看它报的方案靠不靠谱，再决定要不要点头。
③ 一个提醒：它输出 HTML+SVG，不是能拖拽的画布；要改结构得让 AI 重画，发布前记得导出 PNG/SVG。
