先给你看个小东西。

一个从菜单栏落下来的面板，跟手机屏幕差不多大。里面排着一列 AI 工具：Claude Code、Codex、Gemini CLI、Cursor、Copilot CLI……这些熟悉的名字，它都认识。

每个名字后面，跟着它此刻用的模型——Claude Code 用 Kimi K3，Codex 用 DeepSeek V4 Pro，Gemini CLI 挂着 GLM-5.3。

点一下模型名，列表弹开，换一个。完事。

magpie 的面板：每个 AI 工具用什么模型，一屏看全（来源：magpie 官网 usemagpie.ai）

这个工具叫 magpie（喜鹊），MIT 开源，完全跑在你自己的电脑上。9 月 23 日才上线，截至 9 月 28 日，GitHub 上已经 1200 多颗星。

做它的人你可能听过：yetone，开源圈的老面孔——很火的 AI 编程插件 avante.nvim（Neovim 编辑器上的，1.8 万颗星），就出自他手。

它治的，是一个正在变大的痒

AI 工具一多，麻烦就来了。

写代码用 Claude Code，跑任务挂 Codex，偶尔拿 Gemini CLI 查点东西——每个工具背后，是一套自己的模型、自己的密钥、自己格式的配置文件。

偏偏模型更新还快。DeepSeek、Kimi、GLM、Qwen，隔三差五甩出新版本，又便宜又能打。

你想让手上的工具挨个尝尝鲜？可以，先把耐心备好：Claude Code 改 settings.json，Codex 改 config.toml，Gemini CLI 折腾环境变量……三个工具，三套配法。

光是把「该改哪一行」找对，热情就先去一半。

magpie 想干的事，一句话：把这些麻烦，收进一个菜单栏。

它做对了三件事

第一件，把「看」变简单。打开面板，你装的每个工具用什么模型，一屏看完——从 Claude Code、Codex 到 Cursor、Copilot CLI，一共支持 22 种工具（截至 9 月 28 日），名单还在变长。

第二件，把「换」变简单。点开列表，你配过的模型全在里面：DeepSeek、Kimi、GLM、Qwen……而且实时同步——官方说，今早刚发布的模型，下一次刷新，就会出现在列表里。

点开模型列表：DeepSeek、Kimi、GLM……都标着「经由 magpie」（来源：magpie 官网）

细节里藏着功夫：它改你的配置文件时，只动你要改的那一个键——注释、缩进、排序，原样保留；哪天想换回工具自带的模型，一键还原成原样。这种克制，一看就是被配置文件折磨过的人写的。

第三件，是整套设计的底座——它在你电脑上，搭了个「中转站」。

示意图：所有工具连它，它连所有模型；翻译全部在本机完成，不经云端中转（据项目官方说明绘制）

原理说穿了挺妙：Claude Code 只会说「Anthropic 格式」的话，Codex 只会说「OpenAI 格式」的话，各家模型又各有各的口音。

magpie 在中间当翻译——所有工具都连到本机这一个地址（127.0.0.1:3425），它负责把请求翻译成对面听得懂的格式，连「边生成边显示」和调用工具这些细节，都不丢。

它官网首页的标语很直白：每个工具的模型，都收在同一个地方。

顺带一提，密钥也被它收编了：你只在 magpie 里配一次，工具们从此再碰不到厂商的密钥——它们只认识这个本地中转站。

厂商页：密钥在 magpie 里集中管理，模型流进所有 AI 工具的选择器（来源：magpie 官网）

还有些细节，值得单独夸

一是「拼着用」：手里有几个账号、几把密钥？拼成一组，一个没额度了、一个被限流了，自动换下一个顶上，工具那头完全无感。

二是「整套切换」：存几套快照——今天想省钱，一键切「Budget」档；明天要火力全开，切「Focus」档，所有工具的设置一起换。

三是体量克制：桌面版不到 15MB，没用 Electron（一种让软件体积容易变大的常见框架）这类「增肥神器」，用的是系统自带内核；纯命令行版更是只有 7MB。

说几句实话

magpie 不是给所有人准备的。它伺候的是「工具党」：你得本来就在电脑上跑这类 AI 编程工具，手里还得有几个模型的密钥或订阅。

只刷网页版聊天框的朋友，暂时用不上——收藏了解即可。

对了，它实在太年轻：版本号还挂在 0.1，功能还在快速迭代。拿它当尝鲜，正合适。

还有一条得说清楚：它能认出你登录过的订阅——Claude、ChatGPT、Copilot——把它们的模型也摆进统一列表，借给别的工具用。

这条路线在各家条款里属于灰色地带，就不多展开了；知道有这回事就好，用不用、怎么用，请自己按条款权衡。

关键数字（截至 2026-09-28）｜数据来源：GitHub 与项目官方说明

说回开头。它最打动我的，不是功能多，而是「克制」：不注册账号、密钥只存本机、不替你做决定——就是把该顺手的地方，做顺。

模型会越来越多，工具也是。我们能做的，无非是让「选择」这件事，别反过来把我们拖住。

① 怎么装：官网 usemagpie.ai 直接下载（Windows / macOS / Linux 都有）；Mac 老手也能一行命令装好。
