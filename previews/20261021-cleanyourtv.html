10 月 17 号，一个开发者干了件我一直想干、又不敢干的事。

他打开爸妈家的电视。开机先是一条赞助广告，想看 Netflix，手得先等它放完。

他给 Claude Code 输了电视型号，让 AI 顺着家里的 Wi-Fi 连上去，关掉 25 个小米预装包，又写了套新桌面装进去。

弄完，那台电视的首页像 Apple TV：纯黑底，底部四个常用应用。

他把这段发在 X 上，仓库改名 CleanYourTV。四天，1.16 万星。

官方对比图：左边是原厂 Google TV 首页，开机先塞一条赞助广告；右边是换完的样子（来源：项目仓库 docs/stock-vs-new-side.jpg）

它到底动了你电视哪儿

先说清楚它不是什么：不刷机，不破解，也不卸载任何系统应用。

安卓电视和安卓手机一样，留了一个调试通道，叫 ADB。打开它，同一个 Wi-Fi 下的电脑就能给电视下命令。

项目只干三件事：先把已装应用和当前状态抄一份存档；再用 pm disable-user 把广告服务、厂商遥测、推荐内容和用不上的预装包「停用」；最后装一个 390 KB 的桌面，设成默认首页。

停用不等于删除。想反悔，照着存档跑一条恢复命令，状态就改回去了。

它准备了 123 份按型号写好的清单（我数了 examples/ 目录），README 说覆盖 42 个品牌：索尼、TCL、海信、飞利浦、NVIDIA Shield、Chromecast，也有国行的小米电视5 Pro、雷鸟鹤6 PRO、海信 E5Q Pro、Vidda。

换完的桌面：当前应用的名字顶在上方，背景那圈光是从它的海报里取的颜色（来源：项目官方截图）

为什么这周突然火

项目 10 月 17 号才建，现在 11,675 星（截至 10 月 21 日早上 8 点），fork 1,326。

但火的不是它一个。这几天 GitHub 冒出一串同类：free-my-tv、dumbtv、tv-detox，做的都是同一件事，给安卓电视换掉那个塞满广告的首页，而且都是一周内建的新仓库。

其中好几个在简介里直接写了：用 Claude Code 或 Codex 写的。

我的判断是，电视没突然变重要。是「改一件小事」的成本塌了。

以前想动电视桌面，得刷机、翻论坛、赌自己不会把它弄成砖。现在你说清楚需求，AI 去查型号、连设备、一条条试命令；出问题，还有存档能还原。

门槛从「会折腾」，降到了「敢开口」。

本项目与三个同类，一周内先后开源（数据：GitHub 仓库数据，2026-10-21 08:00；本号制图）

说点不好听的

第一，它只认 Android TV 和 Google TV。三星的 Tizen、LG 的 webOS 跑不了它的桌面（LG 那边有社区移植，登记在项目的社区作品页）；Fire TV 只能用清单手动清理，仓库的 AI 提示词不支持它，首页也换不了。桌面本身还要求 Android 8.0 以上。

第二，国行电视要格外小心。README 写得很直白：有些中国大陆版电视会拒绝安装第三方桌面，已记录的 TCL 机型只是例子。不能按品牌猜，得按型号、地区、固件去对清单。

第三，停用系统组件是真会出事。Google TV 的设置向导有抢首页的毛病，原桌面一停用，可能让电视陷入崩溃循环；更阴的是，向导一停用，可能把当初它存下的 Wi-Fi 一起删掉（脚本会跳过这一步，手动做的人容易中招）。有的清单连系统更新服务都停了，想升级固件得先恢复。

第四，ADB 的 5555 端口是明文连接。弄完一定关掉调试、撤销授权，别把这个端口暴露到公网。

还有一条：仓库里没有现成的安装包。要么自己编译（JDK 17 加 Android SDK 34），要么把仓库里的提示词交给 AI 助手，让它按步骤跑。这也是它现在的门槛。

我为什么还是想推荐它

不是因为那个桌面好看。

是因为它把一次「不可逆的折腾」，做成了一套能回滚的操作：动手前先存档，每一步都能撤回，连记录存在电脑哪个文件夹都写明白了（~/.cleanyourtv/）。

这波 AI 项目里，能力强的很多，愿意把自己会犯的错写进说明书的少。

它还专门提醒一句：别把别的机型的清单直接套在自己电视上。

这句话，比任何「一键搞定」都更让我信它。

四个数字看这个项目（数据：GitHub API、项目 README、examples/ 目录；本号制图）

🧰 上手小抄
① 怎么开始：电视「设置 → 关于 → 版本号」连按七次，开开发者选项里的 USB 调试；如果菜单里还有「网络调试 / ADB 调试」，一并打开。电脑装 Claude Code / Codex / Gemini CLI，把仓库的 PROMPT.md 交给它，填上型号。
② 最值得先试：先只做清理、别急着换首页。确认常用 App、HDMI 输入、语音和投屏都正常，再决定要不要装新桌面。
③ 一个提醒：每一步确认前，先让它把恢复记录存好；想反悔就用 tools/restore.sh 加同一份清单，记录在电脑的 ~/.cleanyourtv/。
