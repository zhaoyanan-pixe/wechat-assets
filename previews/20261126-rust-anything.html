Prettier，前端用了十来年的格式化工具。有人把它翻成了 Rust（一种以快、不容易出内存错误著称的编程语言），没搬到的部分自动退回给原来的 Prettier：同一批 2,360 个文件，从 128.6 秒变成 6.9 秒。

快了将近 19 倍。

但让我停下来的不是这个速度。是他怎么证明自己没改坏：动刀之前，先让原来的程序跑了 17,224 遍，把每一次的返回值和异常全录下来。

图注：项目页面，11 月 16 日建仓，到 11 月 26 日晚上 9,864 星（截图：github.com/erkamyaman/rust-anything）

这个项目叫 rust-anything，作者是土耳其开发者 Erkam Yaman（README 署名「Made in Türkiye」）。十天，9,864 星。

改错不可怕，看起来没错才可怕

让 AI 重写一段代码，它有天然的优势：写得快、写得全、态度好。

它也有天然的毛病：说「已完成」的时候，你只能跑几个例子试试。

小脚本无所谓，跑通了就是跑通了。可一套跑了几年的老系统，几十万行，谁都不敢拿几个例子去赌。真正会咬人的从来不是报错，是那种「不崩、不响、结果悄悄变了」，等到有人对账才发现，中间已经错了两周。

rust-anything 想解决的就是这件事：把「有没有改坏」，从一句感觉，变成一个能跑的东西。

它的办法是：先录像

四步，我尽量说人话：

record 录：让原程序跑一批输入，包括自动生成的边界值、容易踩的语义陷阱，还有你自己攒的真实数据。跑完把每个返回值和异常存下来。

bridge 搭壳：生成一个 Rust 包，再生成一层包装。外面的调用代码一个字不用改，原来怎么调，现在还怎么调。

diff 对账：把录像一条条放给新写的 Rust，对不上就不许往下走。

lift 换芯：全部对上了，才把整块换成纯 Rust。原程序一个字不动，随时能退回。

图注：四步流程，依据项目 README 整理（自制图）

关键在第三句：它不是「翻译代码」，是「证明重写」。Rust 那部分还得你和你的 AI 一块块写，它管的是：告诉 AI 该先搬哪块、接口得长什么样、什么时候算完。

还有一层我觉得挺妙：光比输出不够。官方给过一个演示，注册一个账号，本该发一封欢迎邮件。重写版打印的东西一模一样，但发了两次。录像里记了「邮件发出去几次」，回放直接判 0/2 失败。

图注：官方演示动图：输出相同、却多发一封邮件，回放判 0/2 不通过（来源：仓库 docs/assets/effects.gif）

数字确实不难看

图注：五组官方实测数据，Apple M4 上每项跑两遍，先比对输出再计时（数据来源：项目 README 与 docs/real-world.md）

Prettier 那 17,224 次录像里，15,861 次完全由 Rust 跑完，覆盖 10 种语言；剩下没搬的部分回退给 Prettier，所以 17,224 次输出全部逐字节一致。

换句话说，它没说「我们重写了 Prettier」，它说的是「在我们录过的每一件事上，表现得一模一样」。

图注：官方终端演示：59 个真实文件，Prettier 3.63 秒，Rust 版 0.20 秒，输出逐字节相同（来源：仓库 docs/assets/prettier.gif）

我最服气的一点，是它没把话说满。

对 C 语言的项目，README 明写：收益是安全，不是速度。ffmpeg 的 libavutil 搬过去，226,447 次调用全部对得上，但 42 项基准里 18 项持平、8 项更快、剩下 16 项还慢 3% 到 40%。

一个项目肯在首页写「这项我们不如原来」，可信度反而上来了。

三盆冷水

第一盆：它不是一键翻译。 Rust 还是要写，只是被切成小块，一块一块验收。那个「整个服务变成一个 5.3MB 二进制」的案例 json-server，用了九个单元、514 条 HTTP 用例、两个适配器才走到最后。

第二盆：只抓录像覆盖到的。 官方文档写得很干脆：「通过的意思，只是和录过的每一个用例一致，仅此而已」。没人录过的输入、正则里那些刁钻字符、浮点数转文本的格式、哈希表的输出顺序，都可能是漏网的地方。它自己还建议拿真实数据多补几遍。

第三盆：它会真跑你的代码。 整个应用录制的时候，每个用例还会跑两遍。会写文件、连数据库、发网络请求的，就写一遍、连一遍。官方警告写得很直白：在副本上跑，用测试库，环境里别放生产凭证。

你不用 Rust，也能借走这个办法

这期真正想说的其实不是 Rust，是这个顺序：先定验收标准，再动手。

让 AI 改一个表格模板？先挑 20 行典型数据，把现在的计算结果存一份。改完逐行对。

让它重排一个自动流程？先把最近一周的真实输入存下来，改完拿同样的输入再跑一遍。

区别在哪儿？前者你只能看「像不像」，后者你能说「第 17 行差了一个数」。

AI 改东西会越来越快。快到最后，值钱的不再是「改」，而是「怎么证明改对了」。

🧰 上手小抄
① 装：cargo install rust-anything，再 rust-anything setup（会自己给 Claude Code、Codex、Cursor 注册好）；没装 Rust 就去 Releases 下现成的包。
② 最值得先试：不是全量翻，是 rust-anything go --agent claude -- python3 app.py，只把最慢的那个函数搬到 Rust。
③ 一个坑：录像是真跑代码，先在副本上试，别把生产库和生产密钥留给它。
