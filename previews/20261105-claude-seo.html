Google 官方讲 AI 功能的那份文档里有一句话：给 AI 搜索做优化，本质上还是 SEO。这话听着扫兴，但实在。至于是 ChatGPT、Perplexity 那些答案里被反复引用的页面，我看下来赢的也不是玄学，是能被抓到、能被读懂、能被信任。

道理谁都懂。真到要动手，第一个问题就把人卡住了：从哪查？

我特别烦现在那种体检。四五十条红色警告甩过来，每条都在暗示你不行，看完更不知道该先动哪一条。

先看它凭什么涨得这么凶

claude-seo，这几天一直挂在 GitHub 趋势榜上。它是跑在 Claude Code 里的 SEO 体检插件，给它一个网址，10 到 15 分钟，整站查一遍，最后交一张按重要性排好序的行动清单。

它不是一个脚本，是一支队伍：26 个子技能，19 个专职 agent，最多 17 个同时开工。结论落在 Markdown 文件里，要正式点还能出 PDF 和 JSON，文件都留在你自己电脑上。

星数涨得有点吓人。11 月 1 日我按 GitHub 接口扫到 25,292 星，11 月 5 日早上再看，26,651 星。四天涨了一千三百多颗。而这仓库今年 2 月才建。

官方演示：一次 /seo audit，多个专员同时上场，最后汇总成一张排好序的清单（来源：仓库 screenshots/seo-audit-demo.gif）

它查的东西，比一般体检表狠

常规项一个不落：能不能被爬、有没有被收录、站点地图对不对、robots 有没有挡错、跳转链、打开速度。

真正不一样的是两块。

一块叫「AI 会不会引用你」。它会打分，判断 Google 的 AI 概览、AI 模式，还有 ChatGPT、Perplexity、Gemini 有多大概率拿你的页面当答案来源；顺手看一眼你的品牌在维基百科、Reddit、YouTube、领英上有没有影子。做 AI 搜索的人都清楚，这几个地方才是大模型的信息食堂。

另一块更少人想到：AI 代理能不能用你的站。检查项包括 llms.txt、给机器读的 Markdown 版本、WebMCP。听着新，但这是接下来一两年会变成标配的东西。

结构化数据那一块它做得最细。官方贴了一份真报告：某个页面查出 3 段结构化数据、2 个严重问题、5 个警告、18 项通过，评级 B+。严重的那条是，创始人字段只写了 Daniel，联合创始人 Benjamin 明明在页面上，却没进结构化数据。这种错，人眼扫十遍也扫不出来。

官方示意图：从第 48 名爬到第 1 名，被 Google 和四家 AI 引用（示意图，非实测；来源：仓库 assets/readme/v3/hero.svg）

报告的差别，其实在「顺序」

我最在意的是它排的序。查出来的问题会打分排序，每一条都写清三件事：依据是什么、依赖什么前提、改完怎么知道它真的生效了。

这句话看着朴素，其实是分水岭。大部分工具告诉你「这里有 47 个问题」，它告诉你「先改这三条，剩下的等这三条生效再说」。

作者还在 README 里放了张成本对照表，我抄一下：手工做一次 4 到 8 小时，找外包 2 千到 1.5 万美元起，买商业软件 99 到 999 美元一个月。它免费，但要花你的 Claude 额度。表格下面他自己标了一行「价格仅作示意」。

关键数字：仓库 README 与 GitHub API 口径（2026-11-05 08:03 采集）

代价我也说清楚

它不是装个 App 就能点开的。要 Claude Code 1.0.33 以上，Python 3.11 到 3.14，装完还得先跑 /seo setup，备好独立环境和一个无头浏览器。

钱的部分别忽略：一次全套 audit，5 个 agent 跑 Opus，其余跑 Sonnet。Opus 贵，全站查一遍会明显吃掉订阅额度。想先摸摸底，就单页查。

没接 Google 的接口时，速度分是实验室估的，收录情况是从页面推断的，都不是后台真数据。

还有一条容易漏：它跑在 Claude Code 里，页面内容会送去 Anthropic 的模型，不是纯本地。报告文件确实在你电脑上，但别拿它去查不能外传的内网系统。

它自己也不装大神。README 明说：Screaming Frog 这类爬虫爬得更快更深，它干的活是解释、排序，以及陪你把问题追问到底。

仓库页实拍（2026-11-05 08:04）：26,651 星，MIT 协议，最新版 v2.5.0（10 月 22 日发布）

谁该用，谁先别急

接私活做站的人，拿它出第一版体检最划算，十分钟就有一份能拿去谈的东西。

做 AI 搜索、GEO 这行的，它那套检查项可以直接抄成自己的清单，比自己拍脑袋列全。自己有个小站、落地页、作品集的，跑一遍就知道先改哪。

反过来，如果你只是想要一个分数发朋友圈，或者连 Claude Code 都还没装，先别折腾。它给的是清单，清单得有人去改。

一份真报告的骨架：严重、警告、通过分开计数，最后给评级（来源：仓库 README 示例）

🧰 上手小抄
① 装：Claude Code 里依次敲 /plugin marketplace add AgriciDaniel/claude-seo、/plugin install claude-seo@agricidaniel-claude-seo、/seo setup。Windows 也能 git clone 后跑 powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1。
② 先省钱：/seo page <一个页面> 做单页深查，再 /seo geo <网址> 单看 AI 引用概率，别一上来就全套。
③ 一个坑：全套 audit 有 5 个 agent 走 Opus，额度掉得快；没接 Google 接口时，速度和收录只是估算。
