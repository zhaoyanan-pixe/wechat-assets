上周一个线上会，对方语速快到我全程只剩点头的份儿。散了会我翻录音翻了三刻钟，才从里面扒出三个待办。

这周我换了个办法。

一个 5 天前才建仓的开源小工具，叫「知了」。装好以后它就待在菜单栏（Windows 上是托盘）里，会一开，中文字幕自己往外冒，旁边那块小窗一条条写着议题、结论、待办。

知了实时字幕与实时纪要的官方演示动图：左边是英文直播，右边同步生成中文纪要，底部是双语字幕（来源：项目 README 演示图）

它最让我舒服的一点：不往会议室里塞机器人。

以前用过的会议助手，要么得邀请一个“AI 小助手”进会（对方名单里突然多个人，很尴尬），要么得装浏览器插件、改会议设置。知了是直接听电脑正在放出来的声音，会议软件里一个字都不用改，对方完全不知道你在用它。

Mac 上连屏幕共享都拍不到它的纪要窗，要录演示时你手动打开“让对方看到”，不想露就一直藏着。

线下开会也能用。面板上有个“听哪里”，切到“会议室”就用麦克风听桌边的人说话；选“电脑和会议室”（这项要 macOS 26），线上的人从电脑声音听、桌边的人从麦克风听，两边各认各的语言，记在同一份记录里，每句还标着是“现场”还是“线上”。

字幕、记录、纪要，三件事一起干

第一层是字幕。对方开口几秒，它自己认语言，然后翻成你的系统语言。界面有中英日韩四种，跟随系统。

第二层是文字记录。逐句双语，标着是谁说的。认错了人，在实时纪要窗口里改名、合并，或者把某段话改给别人，都行。

第三层才是它真正花力气的地方：纪要不是把话复读一遍，而是边听边归纳议题、要点、结论、待办、人名术语表，还给画了张鱼骨图。点一下某条结论，能跳回原话那一句。

会议记录窗口：按说话人分好名字，逐句英中双语对照（来源：项目 README 官方截图）

有个细节我很喜欢：它会统一人名和术语的写法，还记下听错的变体。按 ⌘F 搜的时候，连错版一起搜出来。“王总”被听成“汪总”这种，搜一次全给你捞出来。

要开口的时候，按住右边那个键

真正解决问题的是这块。

开会你总要说话。按住键盘右边的 ⌥（Windows 上是右 Ctrl），说中文，对方在会议软件里听到的是翻好的英文：声音经过一个虚拟麦克风进会议（Mac 装 BlackHole 2ch，Windows 装 VB-Cable），对面不用装任何东西。

填了 key 之后还能克隆你自己的声音，或者挑一个自然人声。不填也能用系统自带语音，机械一点，但能听懂。

同声传译设置页：按住右 Option 说话、目标语言、声音试听（来源：项目 README 官方截图）

会后：东西都在你自己电脑里

每场会的双语记录、纪要、原始录音，都存在本机，导出 Markdown、Word、SRT 都行。

错过一场会也不怕：把录音或视频拖进去，它转成一场双语记录，点时间轴就从那一句开始放。

官网首页实拍：左边是会议窗口和说话人卡片，右边是实时纪要悬浮面板，下面列着 Zoom、Teams、飞书、腾讯会议、Google Meet、X Spaces 等场景（2026-11-06 09:08 实拍，来源：cicada.indaloop.app）

但它不是免费的午餐

得泼点冷水。

只有 Apple 芯片的 Mac 是真·本机干活：声音不出电脑，不填 key 也能出字幕、翻译、记录。Intel 的老 Mac 从 1.3.0 起也能装，只是识别走云端、得接 key。

Windows、Linux、Android 版是云端识别。也就是说，你的会议声音要分段发给 AI 服务。默认是蚂蚁的 Ling，也能换 OpenRouter、ZenMux 或者任何兼容 OpenAI 接口的服务。这几个平台必须填 key，不填就直接不能用。

钱的事：软件本身不要钱，花钱的是背后那个 AI 服务。开一小时会大约 0.15 到 1 块钱。Ling 每月送 10 元额度，够 10 到 50 小时，日常开会基本等于不花钱。

一张卡看清：5 天 1,489 星、4 个平台、5 个发布版本、开一小时会 0.15～1 元（数据采集于 2026-11-06 09:09）

还有两个坑，装之前先知道：

Mac 版没做苹果公证，Windows 安装包也没代码签名。第一次打开会被系统拦下来：Mac 去“隐私与安全性”里点仍要打开，Windows 点“更多信息 → 仍要运行”。

安卓版录不了微信通话里的声音（系统不让），要听就开外放，选“面对面”。

谁该装

要开英文会、看外语直播、听 X Spaces，或者每周都得整理会议纪要的——装，这东西省下来的时间比装它的时间多。

只是偶尔开个中文小会，手机自带的录音转文字够用——先别折腾，你也不需要再多一个要配 key 的软件。
