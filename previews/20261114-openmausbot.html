左边一列联系人，跟微信几乎一样。点开，聊天框里不是人，是一个正在你电脑上跑命令的 AI。活干到一半它会停下来，把一张卡推到你面前：这条命令，允许吗？

这是 OpenMausBot。今早八点我在 GitHub 上查，2.2 万星（22,176 颗），三个月前才建的库，Apache-2.0 协议，Windows、Mac、Ubuntu 都有安装包。

涨得也快。11 月 9 日我自己的统计里它是 1.77 万星，五天过去，2.2 万。

官方截图：左边一列联系人，每一个都是真的 AI（来源：仓库 docs/screenshots/hero.png）

一个对话框，塞不下一整个班底

我们现在用 AI，基本是一张嘴对一张脸：一个对话框，什么活都往里塞。聊久了，三个毛病一定冒出来。它记不清哪件事归哪个项目；它拿着你的全部权限，动什么都得你盯着；你一去开会，它就停在那儿等你回话。

分角色就顺手得多。它的做法是：每个 bot 是一个联系人，可以单独选模型（背后是本机的 Claude、Codex、Grok 命令行，用你已有的订阅登录），单独写人设，单独分一台电脑，单独决定能碰哪些应用。左边那一列，就是你的班底名单。

还有个细节挺讲究：工作、个人、每个项目各开一个频道，各记各的账、各有一套成员和规矩，不用为每个项目复制一份 bot。

它动手之前，会先递一张卡

官方截图：执行命令、改文件之前，先弹一张允许 / 拒绝的卡（来源：仓库 docs/screenshots/approval-card.png）

这是整个项目里我最服的一点。跑命令、改文件、拿不准的问题，全都变成聊天里的一张卡：允许、拒绝，或者直接在框里回一句。云端电脑和本机电脑走同一套闸门。

为什么值得单拎出来说？因为「AI 替你动手」的风险，从来不在它会不会干，而在你清不清楚自己批准了什么。把每次动手变成一次点击，是慢一点，但你心里有数。

每个 AI 一台电脑，你可以看着它干

官方截图：电脑面板，看实时画面、随时接管（来源：仓库 docs/screenshots/computer-panel.png）

点开「电脑」面板，这个 bot 自己的桌面就在那儿跑：能看实时画面，能接管进去自己操作，也可以让它直接用你这台机器（Windows 支持，要你在设置里明确同意）。

官方截图：连接应用市场，Gmail、Slack、GitHub、Notion 都在里面（来源：仓库 docs/screenshots/marketplace.png）

干活的手也不止一双。通过 Composio 授权一次，Gmail、Slack、GitHub、Notion 等 500 多个应用都能当工具用；还能挂触发器，比如跟它说「每个工作日早上九点，把收件箱总结一份发我」，它自己把卡片建好，随时能暂停、撤销。

它甚至能说话：接上 ElevenLabs、Fish Audio 或 xAI 的声音，按住通话键就能对话，一边干一边汇报，要你批准的时候直接念出来。

三盆冷水

说到这儿，得泼三盆。

第一盆，门槛在第一屏。它自己不产生模型，得你电脑上先装好 claude、codex 或 grok 的命令行并且登录。国内读者多半卡在这：订阅、支付、网络，三道关。所以这篇我写的是它怎么设计的，不是「你今晚就能用上」。

第二盆，云电脑和连接应用都是第三方服务。云电脑由 Boat 提供，试用之后要收费；Composio 也要自己的账号。软件本身免费开源，用起来不一定。

第三盆，它跑得太快，快到不像个稳的东西。8 月建的库，到今天 112 个发布版本；11 月 9 日到 13 日，五天发了六个版本。今早查，713 个 issue 还开着，另有 331 个 PR 在排队。爱追新的人喜欢这个节奏，怕麻烦的人最好等它稳一稳。

据 GitHub API 与 Releases 页面自制，数字均为 2026-11-14 上午实取

还有个小的：Windows 安装包没做代码签名，安装时系统会弹「未知发布者」，要点「更多信息 → 仍要运行」才装得上。

为什么还值得看一眼

作者在 README 里写，2026 年有七周里接连出了四款同类产品（Grok Bot、Meta Muse、OpenAI dots、Cue 这些），共同点是模型、电脑、数据都留在厂商那边；他想做一个开源的版本，跑在你自己的机器上。

这句话我听进去了。今年涨得快的项目，很多在回答同一个问题：AI 从「会聊天」变成「会干活」以后，怎么给它排座位、划权限、留证据。这个项目给的答案很土，也很实在：做成通讯录，一个一个点。

用不用得上另说，这套形状值得记一下。哪天你手上真有三个以上的 AI 在干活，你会需要一张名单。

🧰 上手小抄
① 装：先在电脑上装好 claude 或 codex 命令行并登录；再下 GitHub Releases 里的 OpenMausBot-setup.exe（约 270MB，没签名，装时点「更多信息 → 仍要运行」）
② 先试：只建一个 bot、只给它一件事，看它弹出的第一张审批卡长什么样
③ 提醒：云电脑要另开 Boat 账号、试用后收费；连接应用走 Composio，也要自己的账号
