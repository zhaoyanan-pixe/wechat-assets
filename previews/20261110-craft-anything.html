我这几天盯上一个项目，越看越精神。

它自带的演示里，一个计算器被拆开：点进百分号键那个函数，屏幕上出来五行伪代码，其中一行的注释写着 // the whole trick ——按一下 %，就是把屏幕上的数除以 100。整件事，就这一行。

我先笑了，随后有点发凉。这种「一眼看穿别人怎么写的」活儿，以前是几个工程师围着屏幕抠半天。

项目叫 Craft Anything，ArtCraft 团队做的，10 月 31 日开源。

到今天上午我查了一下：2.4 万星，155 个没关的 issue、125 个待合并的 PR，五个版本累计下载 49.4 万次。十天，五个版本。这个速度，一年也碰不上几回。

它干的事一句话能说清：指着一个网站、App 或游戏，让它看明白是怎么做的，再让你电脑上的 AI 照着造一个自己的版本。

官方截图：选类型（网站 / 应用 / 游戏 / 从零开始），填地址，说一句想要什么，按 Start。右上角那个开关就是净室模式。

它干活的顺序，像个较真的学徒

四步，看、造、比、交。

看：网页按三种屏幕宽度各扫一遍，颜色、字号、间距、点开菜单后的样子全记下来；程序则把函数、字符串、调用关系一条条扒出来。这一步不用 AI，靠的是它自带的 320 个工具。

造，才轮到 AI 上场：叫上你本机的 Claude Code，按你指定的语言和框架起一个新项目。

比重头戏在后头：把你的成品和原件摆在一起量，一页一页给相似度，差哪儿了列成清单。

官方截图：复刻 example.com 的结果。首页 96%、内页 91%、整体 93%，右边还挂着一条没答的问题：「原站的 Logo 和文字能不能复用？」

最讲究的地方，是它「看不看源码」

默认的净室模式（clean room）里，它不读原件的源码、文件、页面源，只用访客能看见的东西：截图、可见文字、量出来的布局和颜色。想往里看的工具会被它拒掉，还提示「要看得切到深度模式」。

深度模式才是全套：读网页 JS、反编译程序，装了 Ghidra 也能接上，用途写得明白——给你自己研究。

我挺喜欢这个开关。它先划了一条「你能看哪一层」的线，再让你自己决定站哪边。

AI 一键生成网站的演示我见太多了，多数是花架子。这个不一样：它把「像不像」变成了数字，每个数字后面挂着证据台账——我说这页 93% 像，依据是这三条，不是我感觉像。

三盆冷水，先泼为敬

第一盆，它还是早期 alpha。作者在 README 里把「能跑的」「写了没实测的」「下一步的」分成三栏摆着，一百多个 issue 也在那儿。别当成熟软件用。

第二盆，它自己不会写代码。你本机得先装好 Claude Code 并登录，走你自己的订阅。Codex 那条线，作者原话是「还没在真实安装上验证过」。

第三盆，净室是「它不肯看什么」的规矩，不是系统沙箱。你的 agent 有什么权限，它就能干什么；装依赖那一步，npm 的安装脚本是真会在你电脑上跑的。

还有一条得说清：它写明了不绕过 DRM、登录和反作弊；复刻页面里的 Logo、照片、文案默认不照搬，要你自己确认有权使用。线是作者划的，守不守在你。

我为什么觉得这事值得看一眼

我们对软件的感觉一直停在「会用」：知道往哪儿点，不知道里头怎么转。这类工具把「里头怎么转」变成了能问出来的东西。

你不用懂汇编，也不用会写 Rust，会问一句「这个功能它怎么实现的」就行，答案后面还带着证据。

造的那半也一样。以前想给自己小店做个预约页，要么学前端，要么花钱找人；现在可以先让它照着你喜欢的那页做一个，再一点点改成自己的。

当然，做出来能不能上线、好不好用是另一回事。工具只负责把你从「想」推到「有个能跑的东西」，审美和判断，它替不了你。

🧰 上手小抄
① 装：去 Releases 页下安装包，Windows 有 .msi 和免安装 zip，macOS 是 dmg；装完直接双击打开，不用碰命令行。
② 先试这条：选「A website」，填一个你自己做过的页面，用净室模式复刻一次，看右侧相似度怎么往上爬。
③ 一个提醒：想让它「造」，本机得先有编码 agent（首推 Claude Code）并登录；拿别人的站点练手前，先确认你有权看它；项目很早期，别拿正经项目开刀。
